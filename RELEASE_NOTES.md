# Sudarshan final planned release — Phase 7

This milestone finalizes the personal harness built through Phases 1–6. It adds
no external Python dependencies, marketplace, hosting platform or new architecture.

## Changes

- Clearer CLI help for project selection, single tasks, models, resume and turn
  limits. Negative turn limits are rejected before creating workspace state.
- Expected workspace/session/provider/task failures produce safe guidance and
  nonzero headless exit status; interactive mode remains available for another
  task. Interrupts retain the existing resume guidance and headless exit 130.
- Six unused imports removed, duplicate task-error/interrupt handling consolidated,
  and the security regression's deliberate subprocess test seam retained.
- Fixed the reproduced Windows memory-lock race: do not resolve a delete-pending
  lock into NTFS's internal deleted-file location; reject lock links and retain
  exclusive creation, bounded retries and the existing memory path checks.
- Reviewed generated bytecode and five redundant Phase 6 logs removed individually.
  All regression tests, benchmark fixtures, demos and historical reports retained.
- Scoped ignore rules cover private/runtime state, local output and editor caches
  while leaving source, documentation, fixture logs and workflows visible.
- [First-run instructions](docs/GETTING_STARTED.md), a
  [current security overview](docs/SECURITY.md), the
  [cleanup report](docs/CLEANUP_REPORT.md) and
  [final project report](FINAL_PROJECT_REPORT.md) added. Existing documentation
  points to current guidance without rewriting historical evidence.
- Existing five-job Windows/Ubuntu/Docker CI workflow enabled on
  `phase-7-final-polish`; no test or security gate removed.

## Compatibility and verification

Python 3.10+; standard library only. The safe default, explicit live-benchmark
opt-in, credential fallbacks, provider/loop protocol, project memory format,
session logs, telemetry schema, and evaluation definitions are preserved.
There is still no pip installer: run `python -m sudarshan` from the checkout.

The baseline full suite ran 369 tests: 355 passed and 14 were skipped on Windows.
Final local and hosted results are recorded in the [final report](FINAL_PROJECT_REPORT.md).
Only mocked provider/offline verification is authorized for this release work;
no live Gemini request or live-product acceptance is claimed.

## Known limits

The [security overview](docs/SECURITY.md) documents local-execution, race,
credential-filtering, remote-lifetime and isolation limits. Context budgets remain
soft estimates. Live SSH, real model performance and generated-product acceptance
remain unverified. This release does not claim production hardening.

Phase 7 is the final planned development milestone. The branch is for review;
merging to main requires approval. After review and merge, use the harness for
personal projects and perform maintenance when needed. No additional development
phase is proposed.
